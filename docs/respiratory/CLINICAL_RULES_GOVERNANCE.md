# Respiratory Clinical Rules Governance

Respiratory rules must be versioned services or governed backend configuration, not permanent frontend thresholds.

Each rule identifies rule ID, guideline/policy, version, jurisdiction, effective date, inputs, outputs, evidence, approver, validation status, and retirement date.

This applies to asthma, COPD, oxygen targets, pulmonary embolism, pneumonia, screening, nodule follow-up, PFT interpretation, pulmonary hypertension, ventilation, and prevention. The current UI intentionally provides no autonomous interpretation because the required governed rule service is not present.
